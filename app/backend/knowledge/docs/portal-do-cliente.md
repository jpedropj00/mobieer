# Portal do cliente

## O que é
O portal fica em mobieerprojetos.com.br/portal. O cliente entra com e-mail e senha próprios, separados do login da equipe.

## O que o cliente faz no portal
- Preenche o **briefing** do projeto.
- Acompanha a **linha do tempo** do projeto e a etapa da produção.
- **Confirma a medição** ou sugere outras datas.
- **Aprova o projeto técnico** ou pede ajustes.
- Vê os **documentos** liberados para ele, como contrato, cronograma e certificado de garantia.
- Acompanha os **pagamentos**.
- Abre **chamados de assistência**, com fotos.
- Preenche a **ficha de eletrodomésticos**.

## Como dar acesso a um cliente
No projeto, aba **Portal do cliente**, a equipe cria ou convida a conta do cliente. O cliente recebe um link para definir a senha.

O cliente também pode se cadastrar sozinho pelo link de cadastro na entrada do portal. Nesse caso ele vê só o briefing até a equipe completar o cadastro.
